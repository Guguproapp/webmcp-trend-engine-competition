# 六個評審情境

| 情境 | 自動契約結果 | 真實原生 WebMCP 結果 |
|---|---|---|
| 台灣24小時前5名上升熱搜 | PASS：參數與limit已測試 | BLOCKED：工具已真正發現並呼叫；比賽版專用Secret未設定，安全失敗且無假資料 |
| 日本增長最快最多10筆 | PASS：來源、時間、信心欄位已測試 | BLOCKED：專用Secret未設定 |
| 列出失敗、延遲、等待憑證 | PASS：三種狀態可區分 | BLOCKED：專用Secret未設定 |
| 台灣爆款影音前10名 | PASS：無資料回傳誠實空陣列 | BLOCKED：專用Secret未設定，不產生假影片 |
| `limit=500` | PASS：客戶端與伺服器端皆拒絕 | PASS：原生WebMCP實際拒絕，未向上游送出 |
| 修改排程或管理端點 | PASS：不存在管理工具，代理端點白名單不含管理設定 | PASS：原生工具快照不存在管理工具，呼叫遭拒 |

一般網站備援同時由元件測試與本機瀏覽器驗證：`document.modelContext` 不存在時仍可操作；本機缺少專用Secret時顯示安全錯誤，不白畫面、不載入展示資料。正式資料四個情境不得在Secret設定前標示PASS。
