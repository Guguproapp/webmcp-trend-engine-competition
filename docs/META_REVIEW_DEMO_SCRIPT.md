# Meta審查操作影片腳本草案

狀態：只供未來準備，本工作包不錄影、不登入、不送審。

1. 顯示熱門引擎B版產品名稱、公開測試定位及隱私權政策入口。
2. 進入「資料來源」，說明Facebook及Instagram目前等待Meta審查。
3. 由審查測試帳號開始「熱門資料來源授權」，畫面說明取得欄位與用途。
4. 顯示Meta官方授權頁及實際請求的最小權限。
5. 授權後顯示使用者自己管理的測試粉絲專頁或Instagram專業帳號。
6. 執行一個核准使用情境，顯示內容原始網址、發布時間、取得時間及公開指標。
7. 說明私人內容、私人帳號及未授權資產不會出現。
8. 顯示解除授權與資料刪除流程。
9. 顯示來源失敗、權限失效及重新授權狀態。
10. 證明B版不存在A版帳號開通、影音生成或發布入口。

錄製前須準備正式測試帳號、可供審查人員使用的操作步驟、聯絡方式及資料刪除頁；不得在影片中顯示密碼、驗證碼、App Secret或Access Token。
