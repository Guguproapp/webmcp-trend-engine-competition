# 熱門引擎 B 版 RC1 審核指南

## 1. 產品與版本

- 產品：熱門引擎｜爆紅流量情報SaaS
- 版本：B版審核候選版 RC1
- 審核網址：<https://trend-engine-b-review.pages.dev/review>

## 2. Mock 資料聲明

目前所有熱門議題、來源訊號、熱度分數及成長數據均為 Mock 審核資料，不代表即時市場情報。全站固定顯示「Mock審核資料｜非即時熱門情報」。

## 3. 建議操作流程

1. 從 `/review` 閱讀產品範圍與資料聲明。
2. 按「開始審核」查看爆紅熱門精選與快速上升議題。
3. 開啟「主題搜尋」，輸入關鍵字並套用來源、時間、熱度、風險及信心篩選。
4. 切換七種排序，確認結果及目前筆數會更新。
5. 開啟任一主題，檢查分數拆解、加扣分、風險、來源證據與資料缺口。
6. 將議題加入觀察，再到觀察清單確認分數與加入時間。
7. 排除議題並選擇原因，再到已排除主題確認及取消排除。
8. 回到 `/review` 按「重設審核資料」，確認恢復 22 個 Mock 主題與 61 筆來源訊號。

## 4. 已完成範圍

- Mock 熱門訊號蒐集、相同主題合併、評分與分級。
- 搜尋、完整篩選、七種排序與條件保存。
- 分數拆解、來源證據、觀察與排除流程。
- 桌面、平板、手機響應式畫面。
- 深層網址 SPA fallback、Mock 標示、資料重設及產品邊界頁。

## 5. 未完成範圍

- 正式熱門 API、新聞 RSS、爬蟲或即時市場資料。
- Supabase、會員、多人資料同步或權限管理。
- AI 文案、圖片、影片、平台 OAuth、自動發布與藍新金流。
- A 版帳號開通與內部營運工作台。

## 6. 已知限制

- 資料保存在目前瀏覽器 Local Storage；不同裝置與瀏覽器不會同步。
- 公開網址不要求登入；noindex 與 robots 設定不是密碼保護。
- Mock 原始連結是安全示意或停用狀態，不代表真實消息來源。
- 重設資料只影響目前瀏覽器中的 B 版熱門情報資料。

## 7. 如何重設資料

開啟 `/review`，按「重設審核資料」。成功訊息應顯示已恢復 22 個 Mock 主題與 61 筆來源訊號。服務只刪除 B 版 `trend-engine.*` namespace，不會執行 `localStorage.clear()`。

## 8. 問題回報資料

請提供：

- 發生時間與使用的正式網址。
- 裝置、作業系統、瀏覽器及畫面尺寸。
- 操作前後步驟、使用的搜尋／篩選條件。
- 預期結果與實際結果。
- 畫面截圖；若可取得，附上 Console 錯誤文字。
- 是否重設資料後仍可重現。
