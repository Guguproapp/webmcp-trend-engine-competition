# 工作包 002C 限制與停止點

本輪只將既有 B 版整理為公開審核候選版並部署，沒有重做熱門功能，也沒有實作：

- 正式熱門來源或爬蟲。
- 會員系統。
- 正式資料庫。
- 產品媒合。
- 內容或媒體生成。
- 第三方授權。
- 跨平台發布。
- 金流。

熱門題目是固定測試情境，不是真實熱門新聞；安全示意連結使用 `example.invalid`。開發資料只保存在目前瀏覽器的 Local Storage。

公開審核網址採知道連結即可存取，沒有會員或密碼保護。`robots.txt`、HTML robots meta 與 `X-Robots-Tag` 用於阻擋搜尋引擎建立索引，不等於私密存取控制。資料重設只影響目前瀏覽器的 B 版 namespace，無法重設其他審核人員瀏覽器中的資料。

A 版另由 `internal/operator-console` 與兩個封存 Tag 保存及續作。B 版分支不包含 A 版帳號、影音及發布功能。

停止點：完成 Cloudflare Pages 免費部署、正式網址逐頁／響應式驗收、證據與 RC1 交付後立即停止，不進入正式 API、會員、金流、OAuth 或 AI 影音。
