# 工作包 002 限制與停止點

本輪沒有實作：

- 正式 Google、Meta、TikTok OAuth 或開發者申請。
- 真正平台帳號註冊、收信、驗證碼、雙重驗證、條款同意。
- 正式 Threads、YouTube、Google Trends、RSS、客戶授權資料或任何爬蟲。
- 產品媒合、品牌內容發想、文案編輯器、AI 腳本、圖片、配音或影片生成。
- 影音合成、真正發布、排程、重試或成效分析。
- 藍新金流、會員方案、點數扣除或完整管理後台。
- Supabase 資料庫、正式 Token 保存、正式部署。

熱門題目是固定測試情境，不是 2026-08-28 真實熱門新聞；安全示意連結使用 `example.invalid`。更新資料只重新執行本機 Mock 彙整與評分，不代表向外部來源取得新資料。

開發版資料只保存在目前瀏覽器的 Local Storage；換瀏覽器、無痕模式或清除網站資料會失去進度。上傳的小型 Logo 以 Data URL 保存，僅適合本輪原型。

停止點：完成「爆紅流量蒐集、評分、排序與篩選 Mock 版」後停止；不進入正式來源、Supabase、生成、發布、金流或部署。
