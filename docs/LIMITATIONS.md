# 工作包003限制與停止點

- GDELT是新聞索引，不是社群互動資料；報導數不會顯示成觀看、按讚或留言。
- YouTube伺服器提供者已完成，但在宗億本人設定官方API金鑰前維持「等待授權」。
- 第一次快照只能建立增速基準；需第二次同主題快照才會顯示真實增速。
- 若只有單一提供者或資料不完整，主題維持「資料蒐集中／證據不足」。
- GDELT官方 HTTPS 憑證於開發時驗證異常；程式目前可由伺服器端嘗試同一官方主機的 HTTP 公開索引並明確標示降級。此路徑不包含秘密，但仍有完整性風險，應持續追蹤官方憑證恢復情況。
- 公開網址不要求登入；noindex 與 robots 不是密碼保護。
- 觀察、排除與篩選偏好仍是單一瀏覽器本機保存，不會跨裝置同步。
- 本輪不包含正式Google Trends／Threads權限、會員、金流、人工智慧內容、商品媒合、影音或發布。

停止點：完成真實GDELT候選版、YouTube安全邊界、D1、測試、Cloudflare部署及線上驗收後停止；YouTube真實證據需宗億本人完成金鑰設定後再驗收。
