# 地區熱搜與八平台RC2限制與停止點

- GDELT是新聞索引，不是社群互動資料；報導數不會顯示成觀看、按讚或留言。
- YouTube官方資料來源已啟用，但目前資料量仍少，不能代表熱門議題覆蓋率足夠。
- 第一次快照只能建立增速基準；需第二次同主題快照才會顯示真實增速。
- 若只有單一提供者或資料不完整，主題維持「資料蒐集中／證據不足」。
- GDELT官方 HTTPS 憑證於開發時驗證異常；程式目前可由伺服器端嘗試同一官方主機的 HTTP 公開索引並明確標示降級。此路徑不包含秘密，但仍有完整性風險，應持續追蹤官方憑證恢復情況。
- 公開網址不要求登入；noindex 與 robots 不是密碼保護。
- 觀察、排除與篩選偏好仍是單一瀏覽器本機保存，不會跨裝置同步。
- Facebook及Instagram尚未送交Meta審查，不能自動搜尋其他公開內容；目前只提供官方搜尋、權限狀態與網址匯入。
- TikTok目前是官方網站／熱門創意中心輔助與使用者分享，不是全平台自動API。
- 抖音、快手、小紅書與B站目前是官方網站輔助、限定網域搜尋與使用者分享，不是官方自動API熱門榜。
- Google熱門搜尋趨勢、Google新聞、YouTube搜尋趨勢、百度搜尋趨勢、百度熱搜、百度指數、微博熱搜及抖音熱榜沒有正式資格時只顯示等待狀態，不提供數值。
- 香港、澳門與中國大陸的地區預設只是操作起點，不代表各平台在該市場已取得完整自動資料。
- 使用者匯入候選只存在目前瀏覽器，數據明確標示尚待驗證，也不會直接進入熱點評分。
- 自動網頁搜尋尚未啟用；系統只開啟搜尋頁，不爬取結果。沒有購買服務或綁信用卡。
- 正式Meta申請仍缺法定名稱、聯絡信箱、隱私權政策、條款、資料刪除頁與回呼網址等宗億本人決策。
- 本輪不包含正式Google Trends／Threads權限、會員、金流、人工智慧內容、商品媒合、影音生成或發布。

停止點：完成B版0.4地區熱搜與八平台RC2、測試、候選Tag及本機三尺寸驗收後停止；不送平台審查、不購買搜尋服務、不部署、不合併回正式B版分支。
