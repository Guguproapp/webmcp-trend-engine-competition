# 測試與 Mock 操作

## 自動測試

```bash
npm run test
npm run typecheck
npm run lint
npm run build
```

測試涵蓋共同資料驗證與完成率、Repository 重新建立後保留進度、平台狀態轉換、五種 callback 結果、state 不一致、過期後重授權、解除連接、兩種首次使用流程，以及不存在密碼／驗證碼欄位。

## 手動 Mock 授權

1. 進入 `/onboarding`。
2. 選「我已有部分帳號」。
3. 將任一平台設為「已有帳號」，儲存後進入進度頁。
4. 點「進入模擬官方授權」。
5. 在清楚標示為 Mock 的頁面選成功、取消、權限不足、過期或錯誤。
6. Callback 結果頁可返回進度或平台連接管理。
7. 成功後可在 `/settings/connections` 模擬 Token 過期、重新授權或解除連接。

「完全沒有帳號」流程會先保存共同資料，再選擇平台並顯示各平台資料預覽。

## 響應式驗收

- 桌面：1440 × 900。
- 平板：768 × 1024。
- 手機：390 × 844。

檢查入口卡片、平台選擇、共同資料、Mock 授權及連接管理；不得有水平溢出，所有主要按鈕需可操作，狀態需同時有文字。
