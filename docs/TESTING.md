# 測試與 Mock 操作

## 自動測試

```bash
npm run test
npm run typecheck
npm run lint
npm run build
```

測試涵蓋工作包 001 原流程，以及工作包 002 的 Mock 蒐集、相同主題合併、集中權重、三種扣分、風險與證據不足狀態、自然事件門檻、搜尋／篩選／排序、規則保存、觀察、排除原因、取消排除與詳情呈現。

## 手動熱門引擎流程

1. 進入 `/trends`，確認日期來自系統、統計與 22 題 Mock 清單可見。
2. 點「更新資料」，確認更新時間與重新彙整結果改變。
3. 到 `/trends/search` 套用關鍵字、分類、來源、時間、分數與風險條件，重新整理確認保留。
4. 點「查看熱度證據」，檢查各來源、熱度變化、分數拆解、加扣分與資料缺口。
5. 加入觀察後到 `/trends/watchlist`，檢查加入時／目前分數及變化。
6. 排除主題並選原因，到 `/trends/excluded` 檢查保存與取消排除。
7. 回到 `/onboarding`，確認工作包 001 仍能操作。

## 手動 Mock 授權

1. 進入 `/onboarding`。
2. 選「我已有部分帳號」。
3. 將任一平台設為「已有帳號」，儲存後進入進度頁。
4. 點「進入模擬官方授權」。
5. 在清楚標示為 Mock 的頁面選成功、取消、權限不足、過期或錯誤。
6. Callback 結果頁可返回進度或平台連接管理。
7. 成功後可在 `/settings/connections` 模擬 Token 過期、重新授權或解除連接。

「完全沒有帳號」流程會先保存共同資料，再選擇平台並顯示各平台資料預覽。

## 響應式驗收

- 桌面：1440 × 900。
- 平板：768 × 1024。
- 手機：390 × 844。

檢查熱門精選、完整篩選、詳情、觀察、排除與帳號開通入口；不得有水平溢出，所有主要按鈕需可操作，分數與風險需同時有文字。
