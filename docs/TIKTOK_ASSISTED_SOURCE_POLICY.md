# TikTok官方網站輔助來源政策

## 允許方式

1. 前往TikTok官方搜尋頁。
2. 前往TikTok官方熱門創意中心。
3. 使用者把公開影片網址貼回熱門引擎。
4. 使用者自行輸入畫面上可見的公開數據。

## 必要標示

- 官方網站搜尋後貼回：`官方網站輔助取得`。
- 使用者從App分享或直接貼上：`使用者分享取得`。
- 使用者輸入觀看或互動數：`使用者提供，尚待驗證`。
- 單一快照：`正在建立增速基準`。

## 禁止事項

- 不保存TikTok密碼、驗證碼、Cookie或登入狀態。
- 不以瀏覽器機器人持續登入、捲動或擷取內容。
- 不宣稱一般使用者授權可搜尋整個TikTok。
- 不把熱門創意中心人工整理資料說成自動API。
- 不把尚未驗證的手動數據顯示為官方熱門排名。
- 不申請不符合商業產品資格的Research API。
