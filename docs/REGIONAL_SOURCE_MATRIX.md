# 地區、熱搜與八平台來源矩陣

## 三個獨立維度

1. 市場地區：中國大陸、台灣、香港、澳門、全部地區。
2. 情報類型：熱搜上升、影音爆紅、雙重爆紅、影音供給缺口、新聞快速增加、證據不足。
3. 影音平台：YouTube、TikTok、Instagram Reels、Facebook Reels、抖音、快手、小紅書、B站。

新聞報導量只能支持「新聞快速增加」，不能當成搜尋量、觀看數或平台熱門排名。雙重爆紅必須同時具有可靠搜尋訊號與可靠影音訊號。

## 地區預設平台

| 地區 | 預設啟用 | 可手動補選 |
|---|---|---|
| 台灣 | YouTube、TikTok、Instagram Reels、Facebook Reels | 其餘四平台 |
| 香港 | YouTube、Instagram Reels、Facebook Reels、小紅書 | TikTok及其餘平台 |
| 澳門 | YouTube、Instagram Reels、Facebook Reels、抖音 | 其餘四平台 |
| 中國大陸 | 抖音、快手、小紅書、B站 | 其餘四平台 |
| 全部地區 | 八平台 | 可自行取消 |

這些只是操作預設值，不代表平台資料已自動取得或已涵蓋整個市場。

## 三類資料來源

### 熱搜來源

| 來源 | 適用地區 | 本輪狀態 |
|---|---|---|
| Google熱門搜尋趨勢 | 台灣、香港、澳門 | 等待官方資格 |
| Google新聞 | 台灣、香港 | 等待官方資格 |
| YouTube搜尋趨勢 | 台灣、香港 | 等待官方資格；既有YouTube影片API不等於搜尋量 |
| 百度搜尋趨勢 | 澳門 | 等待官方資格 |
| 百度熱搜、百度指數、微博熱搜、抖音熱榜 | 中國大陸 | 等待平台權限或官方網站輔助搜尋 |

### 爆紅影音來源

| 平台 | 自動或輔助 | 限制 |
|---|---|---|
| YouTube | 官方API自動取得 | 第一次快照只建立基準；長影音與Shorts分開比較 |
| TikTok | 官方網站輔助、使用者分享 | 不宣稱全平台自動搜尋 |
| Instagram Reels | 官方網站輔助、使用者分享 | 等待Meta權限 |
| Facebook Reels | 官方網站輔助、使用者分享 | 等待Meta權限 |
| 抖音、快手、小紅書、B站 | 官方網站輔助、使用者分享 | 沒有正式介面時不產生假數據 |

### 新聞佐證來源

| 來源 | 適用地區 | 限制 |
|---|---|---|
| GDELT全球新聞資料 | 四個市場 | 只保存新聞索引與衍生密度，不產生搜尋量或影音互動 |
| 台灣可信新聞RSS | 台灣 | 等待來源核准 |
| 可信新聞來源 | 澳門及需要補證市場 | 等待來源核准 |

## 保存相容性

- 既有影音候選仍使用`trend-engine.video-candidates.v1`；新欄位為選填，因此舊資料可讀取。
- 地區搜尋使用獨立`trend-engine.regional-video-search.v1`命名空間。
- 既有觀察、排除與篩選規則的鍵值及資料結構沒有變更。
