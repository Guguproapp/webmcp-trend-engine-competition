# 平台資料保存與刪除原則

## 本工作包實際保存

四平台使用者匯入候選只保存在目前瀏覽器的B版命名空間`trend-engine.video-candidates.v1`，不送至未受保護的公開寫入API。保存欄位包含平台、原始及正規化網址、使用者輸入的標題／作者／公開數據、取得方式、時間、備註、驗證狀態與快照。

GDELT及YouTube正式來源仍保存在Cloudflare D1，保存範圍沿用既有架構：內容識別碼、標題、發布者、原始網址、發布及取得時間、官方可用指標、快照與提供者執行紀錄。新聞不保存全文。

## 禁止保存

- 平台密碼、Email或簡訊驗證碼。
- 瀏覽器Cookie、登入狀態或雙重驗證資料。
- 未經平台核准的私人內容。
- 新聞全文或不必要個人資料。
- 前端Local Storage中的正式API金鑰、OAuth Token或管理Token。

## 保存期限決策

目前公開測試版尚無會員與伺服器端使用者識別，因此使用者匯入資料由使用者清除瀏覽器資料時刪除。正式帳號授權前，須由宗億確認法定名稱、聯絡信箱、正式保存期限及資料刪除服務水準，並提供可操作的刪除頁。
