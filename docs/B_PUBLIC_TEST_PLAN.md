# B版0.3公開測試計畫

## 測試規模與期間

- 人數：5至10人。
- 期間：7至14天。
- 目標：驗證使用者是否能在短時間找到有用且可查證的主題，以及是否有持續使用與付費意願；不以單純觀看數作成功判斷。

## 每位測試者任務

1. 在五分鐘內找到一個可能有用的主題。
2. 開啟至少一筆原始新聞或YouTube來源。
3. 說明自己是否看得懂綜合分數、增速及資料信心。
4. 使用一次關鍵字搜尋或篩選。
5. 將一個主題加入觀察，再視需要移出。
6. 排除一個不適合的主題並選擇原因。
7. 回報願意每天、每週或不定期使用。
8. 回報是否願意付費、可接受價格及不願付費原因。

## 必填觀察紀錄

- 找到第一個有用主題所需時間。
- 每十個主題中被判定有用的數量。
- 原始來源可信度評分及原因。
- 分數是否容易理解；看不懂的欄位。
- 誤判、重複主題及缺漏證據。
- 最需要補充的資料來源。
- 預期使用頻率。
- 付費意願、可接受價格及不願付費原因。
- 裝置、瀏覽器、操作時間、網址與問題截圖。

## 判讀原則

GDELT與YouTube只是目前正式來源；YouTube資料量仍少。分數是決策輔助，不保證爆紅。測試者應開啟原始來源確認。若來源狀態顯示失敗或更新延遲，應連同時間與畫面一起回報。
