# 四大平台資料來源矩陣

| 平台 | 本工作包可用能力 | 取得方式 | 自動化程度 | 正式限制 |
|---|---|---|---|---|
| YouTube | 搜尋現有官方快取、觀看／按讚／留言、不同時間快照 | 官方API自動取得 | 自動 | 配額有限；語言參數只提高相關性；第一次快照不算增速 |
| Facebook | 官方搜尋入口、公開影音網址匯入、權限狀態 | 官方網站輔助／使用者分享 | 輔助 | 公開內容能力尚未申請Meta審查，不回傳假資料 |
| Instagram | 官方搜尋入口、Reels／貼文網址匯入、專業帳號與公開內容狀態 | 官方網站輔助／使用者分享 | 輔助 | 不宣稱完整關鍵字或全Reels搜尋；等待Meta審查 |
| TikTok | 官方搜尋、熱門創意中心、公開影片網址匯入 | 官方網站輔助／使用者分享 | 輔助 | 不是全平台自動API；手動數據尚待驗證 |

補充來源：GDELT以新聞公開資料協助發現事件；合法搜尋引擎目前只開啟限定網域的搜尋頁，尚未啟用自動API。

每筆證據必須保存取得方式與取得時間。只有網址、手動資料或單一快照時只能列為候選，不得判定爆紅。
