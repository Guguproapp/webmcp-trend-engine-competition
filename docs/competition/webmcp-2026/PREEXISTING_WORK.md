# WebMCP比賽前既有工作

下列能力在WebMCP比賽版建立前已經存在於正式B版，不得在比賽簡報、影片、Devpost、GitHub說明或其他提交材料中冒充比賽期間新增功能。

## 既有產品功能

1. 中國大陸、台灣、香港、澳門及全部地區的市場選擇。
2. 熱門議題列表、前五名及展開完整結果。
3. 基本與進階搜尋、篩選及排序。
4. 綜合熱點分數與分數拆解。
5. 基於不同時間有效快照的熱度增速；單一快照只建立基準。
6. 社會共鳴、跨來源程度、資料信心及風險標示。
7. 來源證據、發布者、發布與取得時間、原始來源連結。
8. 觀察、移出觀察、排除、取消排除及撤銷。
9. 搜尋條件、觀察、排除與影音候選的瀏覽器保存封裝。
10. 桌面、平板、手機響應式介面與手機四項底部導覽。

## 既有資料與來源能力

1. GDELT全球新聞資料與新聞佐證定位。
2. YouTube官方API資料、影片統計與快照基準。
3. Facebook、Instagram及TikTok官方網站輔助搜尋與合法網址匯入。
4. YouTube、TikTok、Instagram Reels、Facebook Reels、抖音、快手、小紅書及B站八平台固定入口。
5. YouTube長影音與Shorts短影音共用平台識別，但分開比較基準。
6. 六種情報類型及地區／情報類型／平台三維搜尋。
7. HTTPS、官方主機、危險協定、偽造網域、網址正規化及重複合併防護。
8. Cloudflare Pages Functions、D1、同網域API及加密秘密邊界。

## 既有產品與品質成果

1. 正式產品首頁、使用說明、熱門、搜尋、影音搜尋、來源、觀察、排除及規則路由。
2. 正式中性部署網址`https://trend-engine-app.pages.dev/`。
3. 舊版交付網址`https://trend-engine-b-review.pages.dev/`仍保留。
4. Production Build公開文案、A／B隔離、秘密名稱與展示題目掃描。
5. CSP、安全回應標頭、`robots.txt`與`X-Robots-Tag`禁止搜尋引擎索引。
6. 複製前正式B版已有11個測試檔與168個測試案例通過的封存證據；比賽基準會重新執行品質檢查，不直接沿用舊報告冒充本次結果。

本文件只界定既有成果，不代表所有外部平台均已取得完整自動搜尋權限。沒有正式資格的平台仍只提供等待權限、官方網站輔助或使用者分享入口。
