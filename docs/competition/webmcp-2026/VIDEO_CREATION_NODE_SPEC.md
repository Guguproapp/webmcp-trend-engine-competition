# 篩選後影音創作節點規格

## 範圍與產品邊界

本功能僅位於 WebMCP 比賽版的 `feature/video-creation-node` 分支，用於展示「熱門發現後的人機創作交接」。它不屬於正式 B 版、A 版或熱門雷達服務，且不共用任何原始碼、資料庫、部署、秘密或使用者資料。

本節點不會生成、上傳、發布或排程影音；不呼叫付費人工智慧服務；不向外部影音服務傳送內容。所有輸出皆為使用者可自行修訂、複製到其他影音生成 App 的文字素材。

## 使用流程

1. 使用者從熱門卡片、主題詳情或雷達搜尋結果點選「建立影音創作稿」。
2. 系統帶入主題、摘要、系統分數與來源數；外部標題與摘要一律視為未受信任素材。
3. 使用者可自行寫創作方向，或選擇安全的本機建議格式，並設定比例、節奏與視覺風格。
4. 使用者按下「產生創作建議」，取得三個前三秒鉤子、旁白腳本、四段分鏡、通用文字轉影片指令、圖片轉影片動作指令及人工查證提醒。
5. 使用者逐段或一次複製完整創作包，貼到自行選擇的工具；發布前由使用者查證與取得素材權利。

## 指令可攜性

文字轉影片指令固定使用自然語言欄位：主體、場景、動作、鏡頭、光線、風格、節奏、比例與分鏡。它不採用任何單一供應商的專有語法，也不在輸出中推薦或暗示特定付費工具。

## 資料安全與真實性

- 使用者輸入限制 500 字；主題與摘要在顯示及規劃前移除控制字元與危險標記。
- 沒有來源、只有一次快照、資料延遲或分數不足時，輸出皆保留查證提醒，絕不補造熱門事實、觀看數或增速。
- 系統分數只可說明為系統評估，不能改寫成搜尋次數、觀看數或爆紅保證。
- 提醒使用者確認來源、人物、日期、數字、引述、肖像、商標、音樂與人工智慧內容揭露義務。

## 驗收條件

- 既有主題與雷達候選都可進入工作區。
- 使用者指令與安全建議格式均可產生六類交付內容。
- 每一類內容和完整創作包都可複製。
- 頁面明確標示「本機規則產生」與「尚未呼叫付費人工智慧服務」。
- 桌面、平板、手機的主要控制至少 44px，且沒有水平溢出。
