# 三分鐘 WebMCP 比賽 DEMO 腳本

> 本腳本是先前五工具實驗的歷史證據。目前評審流程改用六個熱門雷達唯讀工具，請依 [RADAR_DEMO_SCRIPT.md](./RADAR_DEMO_SCRIPT.md) 操作。

## 事前準備

- 使用 ChatGPT 內建瀏覽器或已啟用 WebMCP 測試功能的相容 Chrome。
- 開啟 `/agent-workspace`，確認顯示「原生 WebMCP 已就緒」。
- 畫面錄製時同時保留繁體中文 UI 與英文證據標題。

## 00:00–00:25｜界定新增成果

旁白：熱門清單、分數、來源與觀察是比賽前既有能力；本次新增的是五個 WebMCP 工具與真人確認安全流程。

展示：`Native tool status`、`3 read-only + 2 human-confirmed writes`。

## 00:25–00:55｜搜尋最多三個候選

對代理說：

> 請用 search_trends 找出台灣、全部平台、最近 24 小時與人工智慧相關的熱門議題，最多三個。

展示結構化輸出與工作區三張候選卡：`trend_id`、地區、平台、分數、資料狀態與限制。

## 00:55–01:30｜取得證據與來源狀態

對代理說：

> 請用 get_trend_evidence 查看第一個候選，再用 get_source_status 說明來源限制。

展示：正式來源資料、系統計算分數、資料不足、來源限制、`External untrusted content`。

## 01:30–02:05｜加入觀察並真人確認

對代理說：

> 請把第一個候選加入觀察。

畫面必須停在真人確認。旁白：代理沒有確認參數，確認前資料不變。真人點「確認加入觀察」，顯示成功與撤銷。

## 02:05–02:35｜排除另一主題

對代理說：

> 請以「風險太高」排除第二個候選。

再次展示真人確認，點「確認排除主題」，顯示成功。

## 02:35–02:55｜撤銷

真人點「撤銷操作 / Undo」，展示狀態恢復與稽核結果 `undone`。

## 02:55–03:00｜結論

旁白：工具只在比賽版、本機匿名 Session 操作；沒有正式 B 版 D1、秘密、會員、金流、Push 或公開部署。

## 失敗備案

- 原生 API 不可用：清楚顯示「安全降級」，停止原生工具宣稱；不要用一般按鈕或自建 Polyfill 冒充。
- 來源無資料：展示資料不足與來源限制，不補假候選或假增速。
- 寫入取消／逾時／Abort：展示資料未變更與對應結果。
