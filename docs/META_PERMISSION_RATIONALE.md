# Meta權限使用理由草案

狀態：草案，尚未提交Meta。

## Facebook公開內容

熱門引擎希望在取得Meta正式審查核准後，分析公開粉絲專頁中與使用者指定關鍵字相關的公開影音證據。用途限於顯示原始來源、發布時間、公開互動指標、取得時間及跨來源佐證；不讀取私人帳號、私人社團、私人訊息或未授權內容。

未取得權限前，產品只允許使用者前往Facebook官方搜尋，並自行貼回可公開開啟的網址。這些資料明確標示為官方網站輔助或使用者分享取得，不會標示成官方API自動取得。

## Instagram專業帳號與公開內容

熱門引擎希望讓Instagram專業帳號持有人以Meta官方授權連接自己的帳號，並在取得公開內容權限後，以核准的主題標籤能力尋找近期公開內容。產品不宣稱能搜尋全部Instagram或全部Reels。

## 最小資料原則

- 只保存內容識別碼、標題或說明、發布者、原始網址、發布與取得時間及平台核准的公開指標。
- 不保存平台密碼、驗證碼、登入Cookie、私人訊息或完整個人檔案。
- 正式Token只允許伺服器端加密保存。
- 使用者可要求解除授權及刪除已授權資料。

正式送審前須依Meta當時的產品、權限名稱及審查表單重新核對，不得把本草案直接當成已核准內容。
