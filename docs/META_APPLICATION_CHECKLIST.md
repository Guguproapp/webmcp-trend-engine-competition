# Meta應用程式申請準備清單

本文件只供準備，不代表已向Meta送審。宗億必須親自處理登入、雙重驗證、企業資料確認與送出申請；不得把密碼、驗證碼或正式Token交給Codex。

## 目前程式狀態

- Facebook：提供官方搜尋入口與公開網址匯入；公開內容權限狀態為「尚未申請」。
- Instagram：提供官方搜尋入口與Reels／貼文網址匯入；專業帳號及公開內容權限為「尚未申請」。
- Provider邊界已建立；沒有正式憑證時只回傳空結果，不會假裝連線成功。

## 送審前必要項目

- [ ] 宗億本人建立及驗證Meta開發者帳號。
- [ ] 確認公司或產品法定名稱（待宗億確認）。
- [ ] 確認對外聯絡信箱（待宗億確認）。
- [ ] 準備可管理的Facebook測試粉絲專頁。
- [ ] 準備Instagram專業帳號並連接測試粉絲專頁。
- [ ] 建立正式Meta應用程式及測試使用者。
- [ ] 提供可公開讀取的隱私權政策。
- [ ] 提供使用條款。
- [ ] 提供資料刪除說明及可操作入口。
- [ ] 確認正式網域與HTTPS。
- [ ] 建立獨立的熱門資料來源授權回呼網址。
- [ ] 設定OAuth state、PKCE、回呼驗證及伺服器端Token加密保存。
- [ ] 依實際使用情境填寫權限理由。
- [ ] 錄製完整審查操作影片。
- [ ] 確認測試人員不會進入A版功能。

## 現有缺口

目前專案查無正式隱私權政策、使用條款、資料刪除頁、法定名稱、對外聯絡信箱與Meta回呼網址。未取得宗億確認前不得以假資料部署政策頁，也不得送審。
